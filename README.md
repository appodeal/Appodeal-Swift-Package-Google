# Appodeal Google AdMob Adapter - Swift Package

Swift Package Manager distribution of AppodealGoogleAdMobAdapter (APDGoogleAdMobAdapter).

## Installation

Add this repository URL to your Package.swift or Xcode project:
```
https://github.com/appodeal/Appodeal-Swift-Package-Google
```

## Product Names

This package provides two product names for compatibility:
- `AppodealGoogleAdMobAdapter` - Primary product name
- `APDGoogleAdMobAdapter` - Legacy compatibility alias

## Requirements
- iOS 15.0+
- Xcode 15.0+
- Swift 5.9+

## Dependencies
- Google Mobile Ads SDK 13.5.0+
- Appodeal SDK 4.3.0+
